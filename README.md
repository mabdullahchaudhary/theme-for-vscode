# 🎨 EazyPizy Themes

Welcome to **EazyPizy Themes** — a collection of world-class, highly optimized dark themes for VS Code. Built specifically for modern developers, these themes offer razor-sharp contrast, reducing eye strain while making your code pop on screen. 

Perfectly tuned for **MERN Stack (React, Node.js, Express, MongoDB)** and **C++** development.

---

## 🚀 Features
- **Deep Slate/Ocean Backgrounds:** Premium aesthetics that don't hurt your eyes during long coding sessions.
- **Neon Accents:** High-contrast separation for tags, strings, and functions.
- **Scenario-Level Scoping:** Specific TextMate scopes for React components, C++ pointers, and memory management macros.
- **UI Harmony:** Fully customized activity bars, sidebars, and terminal ANSI colors.

---

## 📥 How to Install

### Option 1: Install via VSIX (Recommended)
1. Download the latest `.vsix` file from the [Releases](#) section.
2. Open VS Code and go to the **Extensions** panel (`Ctrl + Shift + X`).
3. Click the three dots `...` in the top right corner.
4. Select **"Install from VSIX..."** and choose the downloaded file.
5. Go to Settings (`Ctrl + K` `Ctrl + T`) and select your favorite **EazyPizy** variant!

### Option 2: Build Locally
1. Clone the repository: `git clone https://github.com/yourusername/eazypizy-themes.git`
2. Navigate to the folder: `cd eazypizy-themes`
3. Press `F5` in VS Code to run and test the theme in the Extension Development Host.
