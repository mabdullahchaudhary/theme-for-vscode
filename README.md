# Theme for VSCode

## Theme Variants

- **Light Mode**: A bright and light theme suitable for daytime use.
- **Dark Mode**: A soothing dark theme for low-light environments.

## Quick Start

1. Install the theme from the VSCode marketplace.
2. Open VSCode settings, and search for "Color Theme."
3. Select your desired theme variant from the dropdown.

## Customization

You can customize the color settings of the theme by adding specific colors in your `settings.json` file. Example:

```json
"workbench.colorCustomizations": {
    "editor.background": "#282c34"
}
```
